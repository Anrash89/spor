    Как устроена случайность?

    Код нового заезда берётся из crypto.getRandomValues. Из него создаются отдельные генераторы трассы, стартовой расстановки и поведения шариков. У всех одинаковые параметры. Имена, цвет и фото не участвуют в расчётах. Это аркадная симуляция движения и столкновений, а не точная модель механики.

    Повтор использует тот же код, состав, порядок и настройки. При одинаковой версии игры итог тот же, включая при ускорении. Код — для воспроизводимости, не криптографическое доказательство честности.
