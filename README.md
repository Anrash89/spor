# Пусть катится

**Бюро случайных решений.** Подпиши шарики, добавь фотографии и устрой минутную гонку. Первый на финише — выбранный вариант.

## Самый быстрый запуск

Открой **PLAY.html** двойным щелчком в Chrome, Edge, Firefox или Safari. Устанавливать ничего не нужно, интернет не нужен. Вся игра, 3D-движок, графика и звуки внутри файла. Если браузер ограничивает локальное сохранение, сама гонка продолжит работать; для надёжного сохранения используй сайт.

## Опубликовать на GitHub Pages

1. Создай публичный репозиторий на GitHub, например `marble-choice`.
2. Загрузи **содержимое** этого проекта. Папка `docs` должна оказаться прямо в корне репозитория, а не внутри ещё одной папки `marble-choice`.
3. Открой **Settings → Pages**.
4. В **Build and deployment → Source** выбери **Deploy from a branch**.
5. Выбери ветку **main**, папку **/docs**, нажми **Save**.
6. После завершения публикации GitHub покажет ссылку на сайт. Ею можно делиться.

Подробности: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

Сборка, API-ключи, платный сервер, база данных и npm для публикации не нужны. Все пути относительные, поэтому сайт работает и в подпапке репозитория. `.nojekyll` отключает обработку файлов Jekyll.

## Что умеет

- 2–24 участника: имена, собственные фото, быстрый ввод списком.
- Случайный трёхмерный серпантин: 9–13 поворотов, разные ширина размаха, направление и декорации.
- Мягкая рисованная стилистика: матовые материалы, контуры, бумажные холмы, деревья и флажки.
- 15 участков с препятствиями: маятники, отбойники, ускорители, трамплины и ремонтные ворота.
- Прочность, повреждения, замедление от ударов; при 0 прочности — ремонт на 2,2 секунды, без выбывания.
- Примерная длительность 45, 60 или 90 секунд. Настройка 60 секунд обычно даёт финиш около минуты.
- Скорость показа ×1 / ×2 / ×4; она не меняет исход симуляции.
- Обзорная камера, слежение за лидером или участником, поворот и масштаб, полноэкранный режим.
- Синтезированные звуки ударов, ускорителей, отсчёта и победы; лёгкий музыкальный цикл. Включение кнопкой ♫.
- Итоговая таблица, история последних 20 гонок, точный повтор, выгрузка результата в JSON.
- Ссылка с вариантами и настройками. **Фотографии и история в ссылку не входят.**
- Адаптация для узких экранов, сенсорное управление, клавиши Пробел / C / M.
- Автоматическая пауза при уходе со вкладки. Открытые окна помощи также приостанавливают гонку.
- Резервный программный рендерер Canvas для браузеров с отключённым WebGL.

## Управление

| Действие | Управление |
|---|---|
| Загрузить / заменить фото | Цветной круг у участника |
| Запуск / пауза | Кнопка или Пробел |
| Сменить камеру | Кнопка или C |
| Следить за конкретным шариком | Участник в таблице гонки |
| Повернуть сцену | Перетаскивание мышью / одним пальцем |
| Приблизить / отдалить | Колёсико / два пальца |
| Включить / выключить звук | ♫ или M |
| Применить код | «Как это работает» → поле внизу |

## Случайность и воспроизводимость

Новый код создаётся через `crypto.getRandomValues`. От него получаются независимые псевдослучайные потоки для стартового порядка, событий трассы и поведения каждого шарика. Все участники имеют одинаковые параметры. Имена, цвета и фото не участвуют в генерации результата.

Победитель не назначается заранее: шарики по мере движения получают случайный темп и цель поперечного перемещения, встречают препятствия, теряют скорость, ускоряются и пересекают финиш. Парные взаимодействия симметричны. Финишное время интерполируется внутри шага 1/60 секунды, а не определяется порядком обхода массива.

Это **аркадная симуляция**, не полноценный rigid-body движок. Движение рассчитывается в координатах вдоль / поперёк трассы; на 3D-серпантин оно проецируется при рисовании. Длительность нормирована, чтобы новый маршрут не превратил минутную гонку в десятиминутную. Картинка следует состоянию симуляции, а не обратному сценарию с заранее выбранным победителем.

Одинаковые код, порядок участников, число участников, длительность, настройка повреждений и версия игры дают один и тот же результат. «Повторить заезд» восстанавливает их автоматически. Для ручного повтора одного кода недостаточно: нужен и исходный состав с настройками. Пробелы, имена и картинки на механику не влияют. История хранит данные для повтора **без фотографий**, чтобы не переполнять память.

Проверка 600 независимых кодов с 6 участниками: победы `100 / 98 / 94 / 105 / 96 / 107`. Это проверка грубого перекоса, а не математическое доказательство равномерности. Для денежных розыгрышей и независимой проверки честности эта клиентская игра не предназначена.

## Данные и приватность

Сайт не отправляет фото или настройки на сервер. Картинки обрезаются в квадрат 128×128 и сохраняются в локальном хранилище браузера вместе с участниками. Для удаления фото можно удалить участника и добавить его заново. Историю можно очистить отдельной кнопкой. Данные разных браузеров / устройств не синхронизируются.

Ссылка передаёт текст вариантов в URL-фрагменте. Любой, у кого есть эта ссылка, может увидеть включённые в неё варианты. Файлы результатов JSON могут содержать фотографии текущего заезда — делись ими осознанно.

## Исходники

- `docs/index.html`, `style.css` — интерфейс.
- `docs/app.js` — состояния приложения, фото, сохранение, управление.
- `docs/engine.js` — чистая фиксированная симуляция и генераторы случайных чисел.
- `docs/world.js` — процедурная геометрия, материалы, камера, анимации.
- `docs/software-renderer.js` — резервная CPU-проекция той же сцены.
- `docs/audio.js` — Web Audio синтез.
- `docs/vendor/three.module.js` — локальная копия Three.js r169, MIT.
- `tests.mjs` — воспроизводимость, независимость от ускорения и оформления, завершение гонок, баланс.
- `build.mjs` — сборка автономного `PLAY.html`.

Для разработки, из папки проекта:

```sh
python3 -m http.server 8080 --directory docs
```

Затем открой `http://localhost:8080`. На Windows при необходимости используй `py` вместо `python3`.

Проверки (Node.js 18+):

```sh
npm test
```

Пересобрать `PLAY.html` после изменения исходников:

```sh
npm install
npm run build
```

## Проверено

625 автоматических прогонов: повторяемость, четыре способа пакетирования шагов, неизменность результата при смене имён / фото / цвета, 2 / 12 / 24 участника, три длительности, включённые и выключенные повреждения, завершение всех участников и допустимые границы состояния.

В браузере проверены полный заезд до финиша, таблица результатов, повтор, массовый ввод, загрузка фото, мобильная компоновка при ширине 390 px и автономная сборка. Включение аудиоконтекста проверено; субъективное качество звука не оценивалось. В тестовом окружении WebGL отключён: визуально проверен совместимый Canvas-режим; аппаратный WebGL-режим требует проверки на целевом устройстве. При отключённом WebGL нет аппаратных теней, а большое число участников может снизить частоту кадров.

Лицензии: исходный код проекта — MIT; Three.js — отдельная MIT-лицензия в `docs/vendor/THREE-LICENSE.txt`. Графика процедурная, музыка и эффекты синтезируются локально. Внешних шрифтов, картинок, CDN и запросов к API нет.
