# MARBLE CIRCUIT — версия 2

Футуристичные гонки шариков для случайного выбора. Подпиши варианты, добавь фотографии и запусти заезд: побеждает тот, кто первым пересечёт финиш.

## Запуск

Открой **PLAY.html** двойным щелчком в современном Chrome, Edge, Firefox или Safari. Это автономная сборка: игра, Three.js, графика и синтезированные звуки находятся внутри файла. Интернет и установка не нужны. Если браузер ограничивает локальное сохранение, гонки продолжат работать; сохранение состава и истории надёжнее при запуске сайта.

## Разместить на GitHub Pages

1. Создай публичный репозиторий, например `marble-circuit`.
2. Загрузи **содержимое** проекта. Папка `docs` должна находиться непосредственно в корне репозитория.
3. Открой **Settings → Pages**.
4. В **Build and deployment → Source** выбери **Deploy from a branch**.
5. Выбери ветку **main**, папку **/docs**, нажми **Save**.
6. Дождись публикации. GitHub покажет адрес сайта, которым можно делиться.

[Инструкция GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).

Сборка на сервере, API-ключи и база данных не нужны. Все зависимости включены, пути относительные. Для обновления уже размещённой первой версии замени файлы в `docs` новыми и дождись повторной публикации Pages.

## Что изменилось во второй версии

- **Шесть разных архитектур трассы:** спираль, восьмёрка, орбитальная, каскад, трилистник и магистраль. Генератор меняет форму, размеры, направление, высотный профиль, число поворотов и препятствия. Это разные геометрии, а не одна дорога с переставленными объектами.
- **Контакты шариков:** устранение пересечений, обмен продольным и поперечным импульсом, отскоки от стен. Удар может изменить порядок участников. Прыжки учитывают высоту.
- **Вращающиеся мельницы-роторы:** четыре лопасти сталкиваются с шариками и передают им скорость.
- **Подвижные шлюзы:** проход сдвигается, створки закрывают дорогу.
- **Воронки:** шарики кружат в чаше, сближаются к центру, взаимодействуют и вылетают обратно на трассу.
- **Тормозные поля, движущиеся отбойники, ускорители, трамплины и ремонтные арки.** Расстановка, направления и скорость движущихся механизмов зависят от кода трассы. Число секторов зависит от длины маршрута и безопасных промежутков между чашами.
- **Автоматическая камера-режиссёр:** плавно облетает лидера, меняет высоту и ракурс, использует отдельный обзор воронок. Дополнительно доступны вращающийся обзор всей трассы, выбранный участник и погоня.
- **Новый интерфейс:** графитовая панель гонки, строгая типографика, кислотные акценты, нумерация участников и телеметрия контактов.

## Возможности

- 2–24 участника, имена и фото, массовый ввод списком.
- Приблизительная длительность 45 / 60 / 90 секунд. Препятствия и столкновения влияют на фактическое время; это ориентир, не жёсткий таймер.
- Ускорение ×1 / ×2 / ×4 без изменения результата.
- Повреждения и прочность. При нуле — восстановление на 1,4 секунды, затем продолжение гонки. Никто не выбывает. Повреждения можно выключить, контакты при этом сохраняются.
- Искры, прыжки, вращение шариков, подвижные механизмы и локально синтезированные звуки.
- Итоговая таблица, история 20 гонок, точный повтор и экспорт результата в JSON.
- Ссылка с вариантами и настройками. Фото и история в неё не включаются.
- Адаптивный интерфейс, сенсорное управление и полный экран.
- Автоматическая пауза при уходе со вкладки; открытые диалоги также останавливают симуляцию.
- Программный Canvas-рендерер, когда WebGL недоступен.

## Случайность, физика и повторы

Свежий код создаётся через `crypto.getRandomValues`. Из него получаются независимые псевдослучайные потоки для геометрии, препятствий, стартовой сетки и поведения шариков. Все шарики имеют одинаковые физические параметры; стартовые позиции перемешиваются. Имя, цвет и фотография не влияют на исход.

Победитель **не назначается заранее**. Шарики получают случайный темп и боковое направление, проходят препятствия, сталкиваются и пересекают финиш. Время финиша интерполируется внутри шага симуляции. При редком точном совпадении времени используется случайный приоритет из кода.

Физика аркадная: расчёт идёт в координатах вдоль и поперёк поверхности, с отдельной высотой прыжка. На каждом шаге 1/60 секунды выполняются два подшага и шесть проходов решения парных контактов. Механизмы сталкиваются с шариками как движущиеся окружности и отрезки. Воронка задаёт вращающееся поле сил и выпускает шарик через случайный интервал. Это не универсальный rigid-body движок для свободного падения по произвольным 3D-поверхностям.

Одинаковые код, порядок и число участников, длительность, настройка повреждений и версия игры дают одинаковый результат. «Повторить заезд» восстанавливает настройки. Скорость показа, частота кадров и оформление участников исход не меняют. Новая версия имеет новую механику: коды и результаты v1 с ней несовместимы, история v2 хранится отдельно; сохранённый состав участников v1 подхватывается.

На проверочной выборке из 240 кодов с шестью участниками победы распределились `43 / 35 / 40 / 39 / 39 / 44`. Это проверка грубого перекоса, а не доказательство строго одинаковых вероятностей. Победитель в минутном режиме на этой выборке финишировал не раньше 43,20 с, последний участник — не позже 79,49 с.

Примеры кодов для просмотра архитектур: `COURSE-2` — спираль, `COURSE-9` — восьмёрка, `COURSE-19` — орбитальная, `COURSE-1` — каскад, `COURSE-0` — трилистник, `COURSE-12` — магистраль.

## Данные

Сайт не отправляет фото и настройки на сервер. Картинки обрезаются до квадрата 128×128 и сохраняются вместе с участниками в локальном хранилище. История хранится без фотографий. Ссылка передаёт текст вариантов в URL-фрагменте; получатели ссылки увидят эти варианты. JSON текущего результата может содержать фото. Устройства не синхронизируются.

## Исходники и разработка

| Файл | Назначение |
|---|---|
| `docs/index.html`, `docs/style.css` | Интерфейс |
| `docs/app.js` | Состояния, фото, сохранение, управление |

| `tests.mjs` | Автоматические проверки |
| `build.mjs` | Сборка автономного `PLAY.html` |

Локальный запуск исходников:

```sh
python3 -m http.server 8080 --directory docs
```

Открой `http://localhost:8080`. На Windows при необходимости замени `python3` на `py`.

Проверки (Node.js 18+):

```sh
npm test
```

После изменения исходников пересобери автономный файл:

```sh
npm install
npm run build
```

## Проверено

265 автоматических заездов: воспроизводимость, независимость от оформления и пакетирования шагов, 2 / 6 / 24 участника, три длительности, оба режима повреждений, отсутствие зависших заездов и допустимые состояния. Дополнительно проверены передача импульса, боковое столкновение, совпадающие центры, высота прыжка, механическое действие всех восьми типов препятствий, обращение и выпуск воронки, шесть архитектур и 80 разных геометрий.

Браузерная проверка проведена в резервном Canvas-режиме. В тестовом браузере WebGL отключён; аппаратный режим с тенями необходимо оценивать на целевом устройстве. Canvas использует упрощённую сортировку поверхностей и изображение сфер: возможны артефакты перекрытия, нет аппаратных теней. Субъективное качество синтезированного звука не оценивалось.
